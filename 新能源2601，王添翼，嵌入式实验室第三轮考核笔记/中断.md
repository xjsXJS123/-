# 中断

## 基本概念

打断CPU执行正常程序，转而处理紧急程序，然后返回原暂停的程序继续运行，就叫中断。

## 作用与意义

1、**实时控制**：在确定的时间对相应的事件作出响应，如温度调控
2、**故障处理**：检测到故障需要第一时间处理，如电梯夹人
3、**数据传输**：不确定数据何时会来，如串口数据接收

**意义**：高效处理紧急程序，不会一直占据CPU资源。

## STM32 GPIO外部中断

信号传入 GPIO（决定上下拉，浮空输入）到AFPI(F1)/SYSCFG(F4/F7/H7) 【将GPIO映射到EXTI】到 
EXTI【屏蔽，上升/下降沿响应】 到 
NVIC【控制 使能和优先级】到 CPU

## NVIC

### 基本概念

Nested vector interrupt controller，嵌套向量中断控制器，属于内核

### 中断向量表

定义一块固定的内存，以4字节对齐，存放各个中断服务函数的首地址。中断向量表定义在启动文件，当发生中断，CPU会自动执行对应的中断服务函数。

### 中断优先级基本概念

1、抢占优先级（pre）：高抢占优先级可以打断低抢占优先级中断
2、响应优先级（sub）：当抢占优先级相同时，响应优先级高的先执行
3、自然优先级：中断向量表中的优先级。当以上都相同时，自然优先级高的先执行。

（数值越小，优先级越高）

## EXTI

### 基本概念

**EXTI**（External interrupt/event controller）是STM32中负责管理**外部中断和事件**的控制器。它监测指定输入线的电平变化（如按键按下），并根据配置决定是否向CPU发出中断请求，或仅产生一个内部事件脉冲。

### 核心功能：中断 vs. 事件

##### 1、中断

信号经过中断屏蔽寄存器，送到 NVIC（嵌套向量中断控制器），CPU 暂停当前工作，跳去执行中断服务函数处理 。

##### 2、事件

信号经过事件屏蔽寄存器，直接产生一个脉冲给其他外设（如 ADC、DMA），CPU 不需要介入，效率更高 。

### 硬件原理与关键寄存器

理解下面这条信号通路，就能搞懂EXTI的配置逻辑：

输入线 → 边沿检测 → 或门 → 与门 → NVIC/脉冲

#### 关键寄存器

| 寄存器      | 名称                 | 作用                                                |
| ----------- | -------------------- | --------------------------------------------------- |
| `EXTI_RTSR` | 上升沿触发选择寄存器 | 控制上升沿是否有效                                  |
| `EXTI_FTSR` | 下降沿触发选择寄存器 | 控制下降沿是否有效                                  |
| `EXTI_IMR`  | 中断屏蔽寄存器       | 置1才允许该线产生中断请求                           |
| `EXTI_PR`   | 挂起寄存器           | 中断发生后对应位被置1，**需手动清除**，否则反复触发 |

#### 信号通路说明

1. **边沿检测**：由 `EXTI_RTSR`（上升沿）和 `EXTI_FTSR`（下降沿）控制，决定什么跳变有效。
2. **中断屏蔽**：`EXTI_IMR` 决定是否允许该线产生中断请求。置1才放行。
3. **挂起寄存器**：`EXTI_PR`。中断发生后对应位被置1。**在中断服务函数中通常需要手动清除此位**，否则会反复触发。

### 4. HAL库开发流程（以按键控制LED为例）

#### 第一步：CubeMX配置

1. 将GPIO引脚（如PA0）模式设为 `GPIO_EXTIx`。
2. 在GPIO设置中，选择触发边沿（如按键按下通常选 **下降沿触发** `Falling Edge`）。
3. 在NVIC选项卡中，**使能**对应的EXTI中断线。

#### 第二步：代码编写

- **无需手写中断服务函数**：HAL库已在 `stm32f1xx_it.c` 中定义了 `EXTIx_IRQHandler`，它会自动调用 `HAL_GPIO_EXTI_IRQHandler` 并清除标志位。
- **只需重写回调函数**：在 `main.c` 中重写弱函数 `HAL_GPIO_EXTI_Callback`。

```c
// 示例：按键(PA0)按下翻转LED(PB7)
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    if (GPIO_Pin == GPIO_PIN_0) // 判断是哪个引脚触发
    {
        HAL_GPIO_TogglePin(GPIOB, GPIO_PIN_7);
    }
}
```
